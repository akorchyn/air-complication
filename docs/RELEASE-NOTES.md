**UA Siren is now the default provider: free and no API token required.** A fresh installation checks Kyiv city when opened; change your monitored location and display preferences through Connect IQ mobile settings.

Direct alerts.in.ua integration and its token setting were removed because nationwide detailed responses can exceed Garmin's 64 KiB background memory. Existing users of that provider automatically switch to UA Siren, with a fresh status check required. Ukraine Alarm remains available with its existing API key; existing Ukraine Alarm and UA Siren selections are preserved.

Epix Gen 2, Epix Pro 51 mm and both Venu 4 sizes remain supported. Manual/background refresh, Ukrainian text, case options, Unicode circles and freshness handling are unchanged.

Whole-region requests from the remaining providers can still exceed background memory; city-specific requests are generally smaller but have no guaranteed size bound. Informational only: continue using official air-alert notifications.
