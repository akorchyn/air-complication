# Changelog

## 1.7.0
UA Siren is now the default, with no token required. Removed direct alerts.in.ua integration and automatically migrate its users to UA Siren; Ukraine Alarm remains available.

## 1.6.1
Added Connect IQ Store support for Epix Pro (Gen 2), 51 mm.

## 1.6.0
Moved all configuration to Connect IQ mobile settings, including provider, API tokens, location and display preferences.

## 1.5.1
Fixed a network callback crash that could prevent manual and background updates, including when the phone was disconnected.

## 1.5.0
Opening the app now attempts a refresh. The previous validated status remains visible while fetching.

## 1.4.0
Added Ukrainian status text and default, uppercase and lowercase options.

## 1.3.0
Added Venu 4 support for both 41 mm and 45 mm models, with layouts adapted to each screen.

## 1.2.0
Added optional Unicode status circles. Appearance depends on the watch face's font support.

## 1.1.1
Fixed settings showing outdated selections after returning from a picker.

## 1.1.0
Added Ukraine Alarm and UA Siren alongside alerts.in.ua, plus presets for all Ukrainian regions and additional cities.

## 1.0.0
Initial Epix Gen 2 release with a public air-alert complication, configurable location, background checks, manual refresh and stale-data indication.
